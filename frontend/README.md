# MONO — frontend платформы авторов

Минималистичный интерфейс подписочной платформы на React + Vite. Чёрно-белая палитра, без градиентов.

## Запуск

Нужен установленный Node.js (рекомендуется актуальная LTS-версия).

```bash
npm install
npm run dev
```

Открой адрес, который Vite покажет в терминале (обычно `http://localhost:5173`).

## Что работает в демо

- Переключение разделов навигации
- Создание публикации в локальной ленте
- Загрузка изображения к посту (предпросмотр)
- Лайки и сохранение постов
- Поиск по авторам и текстам публикаций
- Подписка/отписка от авторов в боковом блоке
- Адаптивная мобильная навигация
- Пустые состояния и уведомления

## Важно

Это frontend-прототип: данные живут в состоянии браузера и сбрасываются при перезагрузке. Вход, серверное хранение постов, реальные платежи, комментарии и доступ к закрытым публикациям пока не подключены. Для этого потребуется backend и база данных.
